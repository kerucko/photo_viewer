# Фото — JPG + RAF для macOS

Просмотрщик папок и управляемой библиотеки на Swift для macOS 26+.
Импорт копирует оригиналы без изменений; удаление перемещает файлы в системную Корзину.
JPG/JPEG и RAF с одним именем объединяются в снимок. Четыре вида: значки,
список, колонки, галерея. RAW проявляется через Core Image.

Реализованы боковая панель файловых сведений и EXIF, масштабирование и перемещение
снимка, настройка размера ленты галереи через меню «Вид». Выбранный размер и видимость
панели сохраняются. Два выбранных снимка можно сравнить в галерее с общим масштабом
и перемещением через «Вид → Сравнить выбранные» или кнопку верхней панели.
Добавлены неразрушающие кадрирование и поворот с общей сеткой просмотра.
Папку при новом запуске нужно открыть заново.

| Клавиши | Действие |
| --- | --- |
| ⌘O / ⌘R | Открыть папку / обновить |
| ← / → | Предыдущий / следующий снимок вне колонок; в колонках — родитель / дочерняя папка |
| ↑ / ↓ в колонках | Предыдущая / следующая строка колонки с фокусом |
| Пробел | Галерея / предыдущий режим |
| Tab / Esc при сравнении | Другая панель / завершить сравнение в галерее |
| ⌘= / ⌘− | Увеличить / уменьшить |
| ⌘0 / ⌘1 | Вписать / 100% |
| ⌘I | Показать или скрыть сведения |
| ⌘E | Редактировать основной снимок или активную панель сравнения |
| ⌘⌫ | Переместить все файлы снимка в Корзину с подтверждением |

Команды масштаба доступны в галерее и колонках при загруженном снимке.
В колонках один щелчок по любой части строки открывает папку или выбирает фото;
вход в папку очищает предпросмотр без автоматического выбора первого фото.
→ на фото ничего не делает, ← в корне ничего не делает. ⌘/Shift выделяют группу
фото одной папки; папка всегда выбирается одна. Навигация работает при фокусе
в браузере и сохраняет обычный ввод в текстовых полях и модальных окнах.

## Сравнение двух фото

В обычной галерее выберите один снимок, затем ⌘-щелчком по ленте добавьте второй
и нажмите «Сравнить выбранные». Повторный ⌘-щелчок исключает фото; обычный щелчок
без ⌘ выбирает одно. Команда сравнения доступна при ровно двух выбранных фото.
Кнопка сравнения и JPG/RAW в галерее имеют общий фон с внутренними отступами. Панели расположены
в текущем порядке сортировки, рамка отмечает активную. Щелчок, начало
перетаскивания или Tab активируют панель; ←/→ и лента заменяют её снимок, пропуская
снимок второй панели. Щелчок по уже показанному фото активирует его панель.

Сначала каждый снимок вписан отдельно. Увеличение, 100% и перемещение общие;
первое увеличение исходит из вписывания активного фото. «Вписать» сбрасывает
масштаб и смещение. Замена фото и JPG/RAW сохраняют общий масштаб и смещение; JPG/RAW
и сведения относятся к активной панели. ⌘⌫ перемещает все ресурсы только активного
снимка с подтверждением; ZIP выбранных фото включает оба. Esc или «Завершить
сравнение» возвращают обычную галерею с группой двух фото, пробел — предыдущий вид.

## Кадрирование, поворот и сетка

«Вид → Редактировать», ⌘E или кнопка кадрирования открывают основной снимок
в галерее; из сравнения — активный, сохраняя группу и завершая сравнение.
Рамка перемещается за внутреннюю область и меняется восемью ручками. Доступны
свободный кадр, исходные пропорции, 1:1, 3:2/2:3, 4:3/3:4, 16:9/9:16,
повороты на 90°, горизонтальное отражение и выравнивание −45,0…+45,0° с шагом 0,1°.
Ползунок непрерывный, без полосы делений; при перетаскивании запрашивается тактильный отклик `.generic` на целых градусах без прилипания. Пустые углы обрезаются.

«Готово» сохраняет рецепт, «Отмена» отбрасывает черновик, «Сбросить» возвращает
черновик к оригиналу. JPG/RAW переключается без потери рамки. Во время правок лента
и инспектор скрыты, навигация и файловые операции заблокированы; обновление каталога
отложено. При закрытии изменённого черновика можно сохранить, отбросить или отменить
закрытие; ошибка сохранения оставляет редактор открытым.

Оригиналы не меняются. В библиотеке рецепт хранится в `edits.json`, для обычной
папки — в Application Support приложения, без файлов рядом с фотографиями.
Пара JPG/RAW использует общие относительные координаты без автоматического совмещения
полей кадра. Сохранённые правки видны в миниатюрах, просмотре, колонках и сравнении.
ZIP содержит исходные файлы; экспорт обработанных изображений — будущий пункт 6.

Сетка «Выключена / 3×3 / 6×6» доступна в меню «Вид» и редакторе, сохраняется
независимо от черновика и показывается поверх рамки либо просматриваемого изображения.
В миниатюрах и пикселях результата сетки нет.

## Сборка

```sh
./scripts/swift.sh test --disable-xctest
./scripts/build-app.sh
open dist/PhotoViewer.app
```

Нужны Command Line Tools с Swift 6 и macOS SDK 26+. Сторонних зависимостей нет.
Полный Xcode не обязателен. Сборка предназначена для локального запуска и
подписывается ad-hoc; распространение и notarization не настроены.

## Библиотека и Корзина

В меню «Файл» выберите «Открыть библиотеку…» и создайте или укажите папку хранения.
«Импортировать с SD…» копирует JPG/JPEG/RAF из выбранного источника и подпапок;
«Библиотека» возвращает к сохранённой библиотеке. Импорт проверяет байты SHA256,
даты и расширенные атрибуты, сохраняя встроенные метаданные без перекодирования.
Повторный импорт из того же корня пропускает уже известные файлы; изменения источника
показываются как конфликт, без перезаписи. Идентичность источника пока зависит от
пути и UUID тома: для повторного импорта выбирайте тот же корень.

Кнопка Корзины или ⌘⌫ требует подтверждения со списком файлов; у пары перемещаются
оба ресурса. В обычной папке это открытые файлы, в библиотеке — импортированные копии.
Импорт не меняет источник; удаление библиотечной копии не удаляет файл на SD и
не позволяет повторному импорту автоматически вернуть удалённую копию.
При частичном сбое показывается, какие файлы переместить не удалось; безвозвратного
удаления нет. Во время операций конфликтующие команды заблокированы.

## ZIP-архив

«Файл → Создать ZIP-архив…» или кнопка архива открывает выбор выделенных снимков либо
всей папки/библиотеки. Можно включить нужные расширения, включая файлы без расширения;
показываются количество файлов и исходный объём. Вся папка обходится рекурсивно;
скрытые файлы, папки и их содержимое исключаются из всех вариантов экспорта.
Символьные ссылки сохраняются как ссылки. Библиотека экспортирует
только зарегистрированные неудалённые ресурсы без служебного манифеста.
Источник не меняется. Доступны отмена, выбор места сохранения и показ результата
в Finder. Ошибка или отмена сохраняет прежний ZIP назначения. Подробности и
ограничения проверки метаданных — в [проверках](docs/verification.md).

## Работа с AI-агентами

Для изменений проекта применяется [photo-viewer-ai-flow](.agents/skills/photo-viewer-ai-flow/SKILL.md).
Главный оркестратор отвечает за цель, назначения, зависимости, области записи и
финальную приёмку. Исполнители напрямую обмениваются вопросами и находками через
`collaboration.send_message`, а решения и блокеры передают оркестратору. Неактивного
агента по необходимости возобновляет оркестратор через `collaboration.followup_task`.
Реализацию выполняет отдельный агент; в конце итерации независимые
тестировщик, продуктовый ревьюер и ревьюер архитектуры/качества кода проверяют
результат. Для изменений UI тестировщик получает рендер итогового кода, а для
оболочки окна и toolbar — также снимок полного нативного окна. После трёх проверяющих
отдельный аналитик GPT-6 Luna Max (`gpt-6-luna`, `reasoning_effort="max"`,
`fork_turns="none"`) анализирует изображения. Недоступность нужного рендера или модели
фиксируется как `PARTIAL`; для изменений только документов/навыков этот этап неприменим.
Каждый проверяющий даёт отдельный вердикт; затем агент документации получает
все применимые отчёты и обновляет документы и ворклог. После исправлений UI нужны
новый рендер и повторный анализ изображений. После исправлений тестировщик
повторяет затронутые проверки, а оба ревьюера проверяют обновлённый результат.
Во время проверок результат не изменяется; одновременно работают не более четырёх
агентов, включая оркестратора.
Информационные ответы не требуют flow; навык сам по себе не разрешает commit/push.

Пример запроса: `$photo-viewer-ai-flow исправь навигацию по снимкам и проверь регрессии`.
